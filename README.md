PySlicer 

## Build Environment For Windows
The tool will be build using Python 3.12.10

1. Download and install Python 3.12.10
2. Install Python's Virtual Environment module
```sh
       pip install virtualenv
```
3. Create a python virtual environment
```sh
       python -m venv c:\virtualpython\PYTHON3.12.10
```
4. Activate the python virtual environment
```sh
       c:\virtualpython\PYTHON3.12.10\Scripts\activate.bat
```
5. Change folder to PySlicer
```sh
       cd C:\projects\PySlicer
```
6. Install the required modules
```sh
       pip install -r requirements.txt
```
7. Run build.bat
